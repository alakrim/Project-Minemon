## Interfaces / invariants
Implement exactly the PLAN.md signatures for: `TypeChart` (core/typechart.gd); `SpeciesData`, `MoveData`, `ItemData`, `CombatantView` and `DamageResult` (core/records.gd); `Stats`, `Damage`, `Catch`, `Exp`, `Lives` and `CreatureInstance`; and the `Data` autoload. For `Data`, replace the body of `game/data_registry.gd`; keep `extends Node` and the file name.

**Formulas:**
- **Stats:**
  - HP = floor((2·base+iv)·L/100) + L + 10;
  - other stats = floor((2·base+iv)·L/100) + 5;
  - then each stat × (1 + floor(bond/25)/100), floored.
- **Damage:**
  - Status moves, or a miss, return amount 0. The accuracy roll is `rng.randf()*100 < accuracy × stage multiplier`, and null accuracy never misses.
  - Otherwise: base = floor(floor(floor(2·L/5+2)·power·A/D)/50)+2.
    - A and D are atk/def for physical moves and spa/spd for special moves, after stage multipliers (stage s: (2+max(s,0))/(2+max(-s,0))).
  - Then × STAB 1.5 if the move type is one of the attacker's types × the TypeChart multiplier × crit 2.0 × random 0.85..1.0. The crit chance is 1/16, or 1/4 if `effect.high_crit`.
  - Floor the result, minimum 1 unless effectiveness is 0. `fixed_damage` overrides the calculation (`"level"` means the attacker's level).
- **Catch:** a = (3·max − 2·cur)·catch_rate·ball_mult/(3·max) × status_mult, where status_mult is sleep/freeze 2, paralysis/burn/poison 1.5, otherwise 1. Chance = clamp(a/255, 0, 1); hp_frac stands in for cur/max. `roll` returns `rng.randf() < chance`.
- **Exp:**
  - gain = floor(base_exp·L/7 · (1 + bond/510));
  - `exp_for_level` uses the standard Gen 1–2 curves for all 6 growth rates (level 1 → 0; erratic and fluctuating included);
  - `level_for` is its inverse, capped at 100.
- **Lives:** starts at 3. Deaths 1–3 decrement and return "respawn"; the 4th returns "permadeath".
- **CreatureInstance:** `from_dict(to_dict())` round-trips every field.

## Steps
1. Write the core files listed above and replace the body of data_registry.gd.
2. **Data files:**
   - data/types.json: the full Gen 2 chart, 17 types.
   - data/items.json: poke_ball, great_ball, ultra_ball, master_ball, potion, link_cable.
   - data/species.json: the **complete families** Rattata→Raticate (19, 20), Pidgey→Pidgeotto→Pidgeot (16–18), Cyndaquil→Quilava→Typhlosion (155–157) and Gastly→Haunter→Gengar (92–94), 11 species, so every evolution target exists. Gen 2 values come from PokeAPI (`https://pokeapi.co/api/v2/pokemon-species/<id>` and `/pokemon/<id>`, or the PokeAPI GitHub CSVs).
   - Learnsets: Gen 2 (gold-silver version group) level-up moves up to level 20 only.
   - Design fields (temperament, size_class, body_plan, habitats, eldritch=false): your sensible choice.
   - data/moves.json: every move those learnsets reference, using Gen 2 values. Category follows the Gen 2 type rule:
     - physical: normal, fighting, flying, poison, ground, rock, bug, ghost, steel;
     - special: fire, water, grass, electric, psychic, ice, dragon, dark;
     - status if power is null.
   - archetype/range_m/cast_s/cooldown_s: your sensible choice, consistent across similar moves.
3. **Validation** (`load_all`): check every field against the PLAN.md data contracts (types, enums, ranges, required keys), every learnset move exists, every evolution target exists, and all types are known. Each error is one string naming the file, entry and field, e.g. `species.json[19].catch_rate: 0 not in 3..255`.
4. **Fixture:** tests/fixtures/bad_data/ holds a copy of the shipped data with exactly these 5 faults: a species with `types: []`, a `catch_rate: 0`, `growth_rate: "weird"`, a learnset move `"no_such_move"`, and a move with category `"magic"`. The test asserts 5 errors, each naming its field.
5. **Tests:**
   - one contract test file per interface in tests/contract/, checking that the methods exist and that they return values of the right types;
   - unit tests in tests/unit/ covering at least: damage against one hand-computed case (show the arithmetic in a comment), crit and miss via seeded Rng, catch bounds and ball ordering, stats at L5 and L50 for Cyndaquil, `exp_for_level` at L10 and L100 for every growth rate, Lives respawn/permadeath, the CreatureInstance round-trip, TypeChart dual-type 4× and 0×, `load_all()==[]` on the shipped data, and the fixture's 5 errors.
