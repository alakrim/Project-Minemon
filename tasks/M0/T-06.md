# T-06 — Remove main-thread stutter in world streaming
ID / milestone / wave / risk: T-06 / M0 / wave 4 / high (threading; Opus reviews)
Depends on: T-05 DONE.

## Goal and why
The T-05 verifier measured headless frames of 215–700 ms. Nearly all of it is `ChunkSnapshot.new()` on the main thread (per-voxel GDScript padding and slicing, 7–11 ms each, up to 79 per frame, with no cap). The benchmark also uses engine delta, which under-reports these spikes. The M0 performance gate (1% low ≥ 20 fps) cannot pass like this.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (Invariant 6, Performance gate), tasks/M0/T-05.verdict.md, world/world_streamer.gd, world/chunk_snapshot.gd, world/column_jobs.gd, world/chunk_mesher.gd, game/benchmark.gd.

## Interfaces / invariants
- The main thread may only do O(1)-per-column work when requesting a mesh: copy the 5 raw `PackedByteArray`s (centre plus 4 neighbours) with `.duplicate()`, which is a native copy, plus the neighbours' `top_y`. All padding and slicing moves to the worker thread, inside ColumnJobs.run_mesh before ChunkMesher.build.
  - Keep a `ChunkSnapshot` type, but change its constructor to take raw arrays, or add a static `from_raw(...)` that builds the padded data. In either case it must be called from the worker.
  - Existing snapshot tests must keep passing (adapt the constructors in tests if needed).
- `_drain_results`: re-mesh requests are de-duplicated per frame (a set of columns), and at most 8 mesh requests are issued per frame; the rest stay queued for the next frames. The meshes-applied-per-frame cap (4) stays.
- `game/benchmark.gd`: measure each frame as wall-clock time between `_process` calls using `Time.get_ticks_usec()`, not `delta`. Add `max_frame_ms` as a 9th key, after `min_fps`. A non-numeric or non-positive `--bench-seconds` value prints a warning and uses 60.
- Invariant 6 still holds: no Node or Resource use on worker threads.

## Steps
1. Make the changes above.
2. Add `tools/profile_stream.gd` (not part of check.sh). It runs the main scene logic headless for 15 s along the benchmark path and prints the maximum and the 99th-percentile main-thread ms spent in WorldStreamer `_process`. Measure with `Time.get_ticks_usec()` inside a debug-only code path guarded by a static flag that is off by default. No timing code may run when the flag is off.
3. Tests: dedupe (5 requests for the same column in one frame give 1 job); the cap (20 pending give at most 8 issued per frame); snapshot-from-raw equivalence (the old and new padding give an identical mesh face count and vertex arrays for 3 sample columns); benchmark argument parsing.
