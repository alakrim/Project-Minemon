# T-05 — Integration, benchmark mode, Windows export (.zip)
ID / milestone / wave / risk: T-05 / M0 / wave 3 / medium
Depends on: T-01..T-04 DONE.

## Goal and why
Deliver the M0 demo: a Windows .zip the owner unzips and runs. It shows a generated world to walk through and a 60-second benchmark that writes its results next to the exe. This answers the performance gate (PLAN.md "Performance gate").

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (Performance gate; WorldStreamer and TerrainGenerator interfaces), world/world_streamer.gd (public methods only), entities/player.gd (public vars only), ui/debug_overlay.gd (`set_extra`), game/settings.gd.

## Interfaces / invariants
- **`main.gd`** attached to `Main` in main.tscn (keep the existing node names). On `_ready`:
  - Instance `world/environment.tscn` and a WorldStreamer (seed 1337, `view_radius = Settings.view_radius`) under `World`, and the debug overlay under `UI`.
  - Call `set_focus(Vector3.ZERO)` then `flush()`.
  - Place the player at `(0.5, TerrainGenerator.new(1337).surface_height(0,0) + 2, 0.5)`, set `active = true` once `has_collision_at` is true, then remove `BootCamera`.
  - Every frame: `set_focus(player.global_position)`, and `overlay.set_extra("Chunks", str(loaded_count()))`.
  - Show the "Generating world…" label until the player is active.
- **Benchmark** (`game/benchmark.gd`, a Node added by main.gd when `"--benchmark"` is in `OS.get_cmdline_user_args()`):
  - The duration is 60 s, overridable with the user argument `--bench-seconds=N`.
  - It disables the player and moves the camera along a square path (side 160 m, centred on spawn, height `surface_height + 20`, one lap in the duration), calling `set_focus` each frame.
  - It records frame times, then writes `benchmark_<renderer>_<yyyyMMdd_HHmm>.txt` to `OS.get_executable_path().get_base_dir()` if that is writable, otherwise to `user://`, and quits.
  - The file has exactly these 8 lines in `key: value` form: `avg_fps`, `low1_fps` (1% low), `min_fps`, `max_static_mb`, `peak_columns`, `renderer`, `gpu`, `view_radius`.
- **`export_presets.cfg`:** a "Windows Desktop" preset, x86_64, embed PCK on, exclude filter `packs/*,tools/*,tests/*`.
- **`scripts/export_windows.sh`:**
  - If missing, download `https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_export_templates.tpz` to `.tools/` and extract it to `~/.local/share/godot/export_templates/4.7.2.stable/`. The archive has a `templates/` folder; move its contents.
  - Run `$GODOT --headless --path . --export-release "Windows Desktop" builds/Minemon-M0/Minemon.exe`.
  - Write into builds/Minemon-M0/ with CRLF line endings:
    - `Play (low-end).bat`: `start "" "%~dp0Minemon.exe" --rendering-method gl_compatibility`;
    - `Play (Vulkan).bat`: the same with `--rendering-method mobile`;
    - `Benchmark (low-end).bat` and `Benchmark (Vulkan).bat`: the same commands plus ` -- --benchmark`;
    - `LEIA-ME README.txt`: plain, click-level steps with Portuguese headings and English text. Unzip, double-click "Benchmark (low-end)", do not touch anything for 60 s, then find the new `benchmark_*.txt` file and send it. Then do the same with "Benchmark (Vulkan)". Then double-click "Play (low-end)" to walk around (WASD, mouse, Space, F fly, F3 overlay, Esc frees the mouse). Note that Windows SmartScreen may warn about an unknown app ("More info → Run anyway").
  - Zip the folder to `builds/Minemon-M0-windows.zip`.
- **`tests/smoke/test_main.gd`:** set `Settings.view_radius = 1`, instance main.tscn, process up to 300 frames until the player is active, then assert player active, `loaded_count() >= 9`, and that the player's y is above `surface_height(0,0)`.

## Out of scope / files not to touch / permitted dependencies
- Allowed files: main.tscn (add the script only; no node renames), main.gd, game/benchmark.gd, export_presets.cfg, scripts/export_windows.sh, tests/smoke/test_main.gd, .gitignore.
- No gameplay. No new dependencies beyond the official export templates.

## Acceptance criteria and verification
1. `bash scripts/check.sh` exits 0.
2. `bash scripts/export_windows.sh` exits 0, and `unzip -l builds/Minemon-M0-windows.zip` lists Minemon.exe, the 4 .bat files and the README.
3. `$GODOT --headless --path . -- --benchmark --bench-seconds=5` writes a result file (to `user://` or next to the binary) with all 8 keys. Paste it in your report. Headless fps values are meaningless; only the format is checked.
4. The zip size is reported (target under 150 MB).
