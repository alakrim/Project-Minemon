# T-01 — Project scaffold, tooling, check command
ID / milestone / wave / risk: T-01 / M0 / wave 1 / high (it defines tooling and files everyone depends on)

## Goal and why
Create the Godot 4.7.2 project skeleton, the `Rng` core class and a working `scripts/check.sh`, so that every later task has one command proving the repo is healthy.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (sections "Architecture", "Interfaces" for `Rng`, and "Invariants").

## Interfaces / invariants
- The folder layout matches the PLAN.md "Architecture" tree. Create the empty folders with a `.gitkeep`.
- **project.godot** (T-01 is its only editor in M0):
  - name "Minemon";
  - `rendering/renderer/rendering_method="gl_compatibility"` and `.mobile="gl_compatibility"`;
  - window 1280×720, resizable;
  - main scene `res://main.tscn`;
  - autoloads `Data` → `res://game/data_registry.gd` and `Settings` → `res://game/settings.gd`;
  - the InputMap actions below;
  - the GUT plugin enabled.
- **Autoload stubs:**
  - `game/data_registry.gd`: `extends Node`, with `func load_all(dir: String = "res://data") -> Array[String]: return []`.
  - `game/settings.gd`: `extends Node`, empty.

  Later tasks replace the bodies of these stubs; they must never be renamed.
- **InputMap actions (exactly 18):** `move_forward`(W) `move_back`(S) `move_left`(A) `move_right`(D) `jump`(Space) `sprint`(Shift) `dodge`(Ctrl) `attack`(left mouse) `throw_ball`(right mouse) `move_1` `move_2` `move_3` `move_4`(keys 1–4) `send_out`(Q) `interact`(E) `menu`(Esc) `toggle_debug`(F3) `toggle_fly`(F).
- **main.tscn:** root `Node3D` named `Main`, with children `World` (Node3D), `UI` (CanvasLayer) containing a Label "Minemon M0", and `BootCamera` (Camera3D at (0, 80, 0)). Later tasks add nodes under World and UI and must not rename these.
- **core/rng.gd:** `class_name Rng extends RefCounted`, the full implementation from the PLAN.md interface:
  - wraps a `RandomNumberGenerator` seeded with `seed`;
  - `fork(tag)` returns `Rng.new(hash(str(seed) + tag))`;
  - stores `seed: int` as a public var.

## Steps
1. **`scripts/setup.sh`** (bash, idempotent):
   - Download `https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_linux.x86_64.zip` to `.tools/`, unzip it, and symlink it as `.tools/godot`.
   - `pip install --break-system-packages "gdtoolkit==4.*"`.
   - Skip any step whose result already exists.
2. **GUT:** vendor GUT for Godot 4.x from `https://github.com/bitwes/Gut` (a release zip or tag; check that it supports 4.7) into `addons/gut/`. Add a "Code dependencies" section to `ASSETS_LICENSES.md` with a row for GUT (MIT).
3. **`gdlintrc`:** gdtoolkit defaults with max-line-length 110. Lint and format only files outside `addons/` and `.tools/`.
4. **`scripts/check.sh`** (bash, `set -euo pipefail`, `GODOT=${GODOT:-.tools/godot}`). Print a header per step and stop on the first failure:
   - (a) `gdformat --check` on the lint file set.
   - (b) `gdlint` on the same set.
   - (c) `$GODOT --headless --path . --import`, then fail if its output contains `ERROR:` or `SCRIPT ERROR`.
   - (d) `$GODOT --headless --path . -s addons/gut/gut_cmdln.gd -gdir=res://tests -ginclude_subdirs -gjunit_xml_file=res://.godot/gut_junit.xml -gexit`. Then parse `.godot/gut_junit.xml` with python3 and fail if the total tests is 0, or if failures + errors > 0. Print the counts.
   - (e) Print `CHECK PASSED`.

   Confirm the exact GUT flags against the vendored version's docs and adjust them if they differ. Record what you used in your report.
5. **Tests:**
   - `tests/smoke/test_boot.gd`: instances `main.tscn` and asserts nodes `World`, `UI` and `BootCamera` exist.
   - `tests/unit/test_rng.gd`: same seed gives the same sequence, a different seed gives a different sequence, `fork` is deterministic, and `randi_range` stays in bounds.
6. **`.gitignore`:** `.tools/`, `.godot/`, `builds/`, `packs/*`, `!packs/README.md`. Add `packs/README.md`: "Owner asset pack folder. Format defined in M2."
7. **CLAUDE.md:** replace the "Key commands" section with the setup.sh and check.sh commands.

## Out of scope / files not to touch / permitted dependencies
- No other game logic.
- Allowed files: project.godot, main.tscn, the folder skeleton (.gitkeep files), core/rng.gd, game/data_registry.gd, game/settings.gd, addons/gut/, scripts/setup.sh, scripts/check.sh, gdlintrc, .gitignore, packs/README.md, ASSETS_LICENSES.md, tests/smoke/test_boot.gd, tests/unit/test_rng.gd, and the CLAUDE.md "Key commands" section.
- Permitted dependencies: GUT and gdtoolkit.

## Acceptance criteria and verification
1. From a clean checkout, `bash scripts/setup.sh && bash scripts/check.sh` exits 0, prints test counts above 0, and prints `CHECK PASSED`. A second `setup.sh` run downloads nothing.
2. A temporary failing test makes check.sh exit non-zero. Verify, then remove the test.
3. A temporary format violation makes check.sh exit non-zero. Verify, then revert.
4. Deleting all tests makes check.sh exit non-zero. Verify, then restore them.
5. `grep -c '^[a-z_0-9]*={' project.godot` inside `[input]` shows 18. Show the command you used.
6. `git status --porcelain` shows no `.tools/` or `.godot/` paths.
