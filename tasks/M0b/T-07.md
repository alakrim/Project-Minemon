# T-07 — Screenshot tool (visual review in the container)
ID / milestone / wave / risk: T-07 / M0b / wave 1 / low

## Goal and why
Opus must judge the look of the world before each owner build. We need deterministic screenshots of the real game rendering, made inside the Linux container.

## Read
CLAUDE.md, docs/CONVENTIONS.md, main.gd, game/benchmark.gd (how the camera path and the streamer are driven), world/world_streamer.gd (public API only).

## Interfaces / invariants
- `tools/screenshot.gd`: a Node script that main.gd adds when the user argument `--screenshots=<out_dir>` is present. It works the same way benchmark.gd is added.
  - For each of the 6 shots in `SHOTS`, it does: `set_focus(pos)`, `flush()`, waits 30 frames, places a Camera3D, waits 5 frames, then saves `get_viewport().get_texture().get_image()` as `<out_dir>/<name>.png`. After the last shot it quits.
  - `SHOTS` is a const array of `{name, pos:Vector3, look_at:Vector3}`, found by scanning the seed 1337 terrain with `TerrainGenerator.surface_height`, so each shot frames something meaningful: `plains`, `forest`, `mountain`, `beach_water`, `cliff_close` (close-up of a block face, 3 m away, to judge textures), and `overview` (60 m above the ground, looking at the horizon).
  - Pick the positions with a small helper in `tools/find_shots.gd` (run once) and hard-code the results.
- `scripts/screenshots.sh`:
  - `xvfb-run -a -s "-screen 0 1280x720x24" $GODOT --path . --rendering-method gl_compatibility --resolution 1280x720 -- --screenshots=<abs path builds/shots/<timestamp>>`;
  - prints the output folder;
  - also writes `contact.png`, a 3×2 grid of the 6 shots at half size with labels. Use python3 with Pillow; Pillow is a permitted dev-only dependency, so add it to setup.sh as `pip install --break-system-packages pillow`.
- Not part of check.sh. Must not change gameplay when the argument is absent.

## Steps
Write the files above, run the script, check that the 6 PNGs are real renders (not black or empty), and list their paths in your report.

## Out of scope / files not to touch / permitted dependencies
- Allowed files: tools/screenshot.gd, tools/find_shots.gd, scripts/screenshots.sh, scripts/setup.sh (the Pillow line only), main.gd (only add the screenshot hook, exactly like the benchmark hook).
- Permitted dependency: Pillow (dev only).

## Acceptance criteria and verification
1. `bash scripts/check.sh` exits 0.
2. `bash scripts/screenshots.sh` exits 0 and produces 6 PNGs plus contact.png. Each PNG has more than 1000 distinct colours (check with Pillow) and is not mostly a single colour.
3. Running main without the argument behaves as before (test_main smoke test still passes).
