# T-12 — Lives system datapack (3 lives, 4th death = permadeath)
ID / milestone / wave / risk: T-12 / M0' / wave 1 / medium

## Goal and why
The owner's rule (D-009): each player has 3 lives; the 4th death is permanent. This must work per player in multiplayer and coexist with the Cobblemon Johto adventure map, which may use its own scoreboards. It uses pure vanilla commands, so it is fully text.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (Invariants 3 and 5).

## Interfaces / invariants
- Datapack root: `layer/datapack/minemon/` with `pack.mcmeta` (`pack_format` 48, description "Minemon layer") and `data/minemon/...` plus `data/minecraft/tags/function/load.json` and `tick.json`.
- Every scoreboard objective and tag we create starts with `minemon.`, so it never collides with the map.
- **Objectives:**
  - `minemon.deaths`: deathCount, counted by Minecraft;
  - `minemon.seen`: dummy, deaths already processed;
  - `minemon.lives`: dummy, lives left, for display;
  - `minemon.max`: dummy; a fake player `#max` holds 3;
  - `minemon.check`: a trigger objective so any player can run `/trigger minemon.check` to see their lives in chat.
- **load** (`minemon:load`):
  - creates the objectives if missing; sets `#max minemon.max` to 3 only if it is unset;
  - shows `minemon.lives` in the `list` (tab) display slot, without touching the sidebar the map may use;
  - starts the `minemon:lives/loop` schedule (every 10t);
  - prints a one-line "Minemon layer loaded" message to ops only (`tellraw @a[tag=minemon.debug]` or a plain console message; do not spam players).
- **loop** (every 10 ticks, rescheduled by itself):
  - **New players:** players without the tag `minemon.init` get `seen = deaths` (deaths before install don't count), `lives = #max − 0 = 3`, and the tag. They see a short welcome tellraw: "You have 3 lives. On your 4th death, your journey ends forever."
  - **Process deaths only for living players** (`execute as @e[type=player,tag=minemon.init,tag=!minemon.dead]`, since dead players are not in `@e`), when `deaths > seen`:
    - set `seen = deaths`;
    - lives = #max − (deaths − deaths at init). Store `minemon.base` (deaths at init) to compute this.
  - **Lives ≥ 1:** title the player in red: "N lives left" (subtitle "Be careful…"), with the sound `minecraft:entity.wither.spawn` at volume 0.4 for that player only.
  - **Lives = 0:** title "LAST LIFE" (dark red, subtitle "One more death and it's over"), the same sound, and every 60 s while at 0 lives a subtle actionbar reminder "Last life".
  - **Death beyond the last life (lives < 0):**
    - set gamemode spectator;
    - tag `minemon.dead`;
    - title "YOUR JOURNEY ENDS" with subtitle "Permadeath";
    - tellraw everyone "<player> has fallen forever.";
    - clamp lives to 0.
  - `/trigger minemon.check`: reply in chat with "Lives: N/3" (or "Permadeath" for dead players), then reset the trigger and re-enable it.
- **Admin functions** (op only; they are functions, so only ops can run them):
  - `minemon:lives/give_life` (as @s: +1 life by raising base, capped at #max);
  - `minemon:lives/reset_self` (fresh 3 lives, remove the dead tag, gamemode survival);
  - `minemon:lives/reset_all` (the same for every online player);
  - `minemon:lives/set_max` (documents how to change #max via the scoreboard).
- `layer/datapack/minemon/README.md` documents every objective, tag, function and the in-game checklist.
