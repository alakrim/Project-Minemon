# T-11 — Repo restructure and layer validator
ID / milestone / wave / risk: T-11 / M0' / wave 1 / high (tooling everyone depends on)

## Goal and why
After the pivot (D-022, D-023), main must contain only the text-layer project, plus a check command that catches broken datapack and config files without Minecraft.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md, docs/research/S-08-tooling-delivery-perf.md.

## Steps
1. **Remove the Godot prototype from main** (it is archived on branch `godot-prototype`): `git rm -r -q` addons/ core/ entities/ game/ ui/ vfx/ world/ tests/ assets/ packs/ project.godot main.tscn main.gd *.uid at the root, export_presets.cfg, gdlintrc, scripts/export_windows.sh, scripts/screenshots.sh, and tools/*.gd. Keep data/*.json, docs/, tasks/, ASSETS_LICENSES.md (trim it to a header plus "no third-party assets committed"), .claude/ and .gitignore.
   - Use `git rm` so the removal is staged, but do not commit.
2. **`.gitignore`:** builds/, .tools/, __pycache__/, *.pyc, .claude/worktrees/.
3. **`scripts/setup.sh`** (idempotent): `pip install --break-system-packages "mecha>=0.101" "nbtlib>=1.12"`.
4. **`tools/validate_layer.py`** (python3, stdlib plus nbtlib only). It checks `layer/` and prints `file:line: message` for each problem, exiting 1 on any error.
   - **(a)** Every `.json`, `.mcmeta` and `.json5` (for json5, strip `//` comments first) parses.
   - **(b)** `layer/datapack/*/pack.mcmeta` has `pack.pack_format == 48` and a description. The same applies to `layer/resourcepack/*/pack.mcmeta`, but with `pack_format == 34`.
   - **(c)** Datapack folder names follow the 1.21 singular names: flag `functions/`, `advancements/`, `predicates/`, `loot_tables/`, `item_modifiers/`, `structures/`, `tags/functions/` as errors.
   - **(d)** Every `function <ns>:<path>` and `schedule function <ns>:<path>` reference inside .mcfunction files, and every entry in `tags/function/*.json` `values`, points to an existing `data/<ns>/function/<path>.mcfunction`. Ignore namespaces other than `minemon` unless a file for it exists in layer/.
   - **(e)** .mcfunction hygiene: no tabs, no trailing spaces, no empty file, LF endings.
   - **(f)** File and folder names under data/ are lowercase `[a-z0-9_./-]`.
   - **(g)** `.snbt` files parse with nbtlib.
   - **(h)** A hook `SCHEMAS`, a dict of path-glob → required top-level keys, starts empty with a comment explaining that later tasks fill it from `reference/`.
5. **Tests for the validator:** `tools/tests/test_validate_layer.py` (unittest, stdlib), with fixture mini-packs under `tools/tests/fixtures/`: one good pack, plus one bad pack per rule (a)–(g). Each bad fixture must produce exactly its expected error.
6. **`scripts/check.sh`** (bash, `set -euo pipefail`). In order:
   1. `python3 -m unittest discover -s tools/tests -v`;
   2. `python3 tools/validate_layer.py layer`;
   3. `mecha -m 1.21 <every datapack dir under layer/datapack/>`, but only when at least one .mcfunction exists. Confirm the exact mecha CLI on this version; it must exit non-zero on a bad command.

   Print `CHECK PASSED`. If `layer/` does not exist yet, steps 2 and 3 print "no layer yet" and pass.
7. Update the CLAUDE.md "Key commands" only if your commands differ.

4. `git status` shows the Godot removal staged and no Godot source files left on disk except on the archived branch.
