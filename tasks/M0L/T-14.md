# T-14 — Repo cleanup, Luanti tooling, game assembly, check command
ID / milestone / wave / risk: T-14 / M0 / wave 1 / high (tooling everyone depends on)

## Goal and why
After PIVOT 2 (D-024, D-025), main must hold only the Luanti project, with one command that lints, unit-tests and runs real headless integration tests inside the assembled Minemon game (VoxeLibre plus our mods).

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md, docs/research/S-10-luanti-tooling.md. The working spike scripts are copied in `.tools-seed/` (build_luanti.sh, run_luanti_test.sh, lua_tooling/, mods/), so reuse them.

## Steps
1. **Godot leftovers stay on main for now.** Do NOT delete them: a deletion step was refused by a safety check, and Opus decided to leave the files in place (they are archived on branch `godot-prototype` anyway). Your tooling must simply ignore them. luacheck runs only on `mods/` and `tests/unit`/`tests/integration`, and busted only on `*_spec.lua`. Replace the old Godot `scripts/setup.sh` and `scripts/check.sh` with your new versions (overwrite them; do not delete).
2. **`.gitignore`:** .tools/, builds/, __pycache__/, *.pyc, .claude/worktrees/, .tools-seed/.
3. **`scripts/setup.sh`** (idempotent, quiet when there is nothing to do):
   - (a) The apt packages from S-10, plus lua-check, lua-busted, luajit and lua5.1.
   - (b) Build luantiserver **5.17.0** server-only into `.tools/luanti/`. Clone tag 5.17.0 with depth 1 into `.tools/luanti`, and build in place with the S-10 cmake flags. Skip if `.tools/luanti/bin/luantiserver --version` already reports 5.17.0.
   - (c) Clone VoxeLibre from `https://github.com/VoxeLibre/VoxeLibre` into `.tools/voxelibre`, pinned to the **newest release tag** whose game.conf works with Luanti 5.17 (Opus pinned it: **0.92.3**). Record the pinned tag in `scripts/versions.env` (`LUANTI_TAG=5.17.0`, `VOXELIBRE_TAG=...`), which setup.sh reads.
4. **`scripts/assemble_game.sh`:** recreate `.tools/games/minemon/`:
   - copy `.tools/voxelibre/*` (everything except .git);
   - set game.conf `title = Minemon` and keep the other keys;
   - copy `mods/minemon/` into `games/minemon/mods/minemon/`.
   - If `mods/minemon` does not exist yet, create `mods/minemon/modpack.conf` (`name = minemon`) and a minimal `minemon_core` mod: a `minemon` global table, `minemon.version = "0.1.0"`, and a log line on load. T-15 and T-17 will add more mods.
5. **`scripts/run_luanti_test.sh <test_mod_dir> [timeout_s]`:** adapt the S-10 runner. It creates a fresh world using `gameid = minemon` with the assembled game (set `MINETEST_GAME_PATH`/`LUANTI_GAME_PATH` or pass `--gameid` with the games dir under `.tools/games`; check what 5.17 uses), copies the test mod into `worldmods/`, writes a server config (IPv6 off, bind 127.0.0.1, a free port, `mcl_` settings left at defaults), runs it with a timeout, prints the server log tail on failure, and exits 0/1 from `test_result.txt`.
5b. Integration test mods that need file I/O (e.g. tests/integration/data) must be listed in `secure.trusted_mods` in the runner's server config. The runner should add every test mod name to `secure.trusted_mods` automatically.
6. **`tests/integration/smoke/`:** a test mod asserting that:
   - (a) `minemon` and `minemon.version` exist;
   - (b) VoxeLibre loaded (`core.get_modpath("mcl_core")` and `core.registered_nodes["mcl_core:stone"]` exist);
   - (c) `mcl_mobs` exists and exposes `register_mob`;
   - (d) after `core.emerge_area` around (0,0,0) completes, at least one non-air node exists in −16..16;
   - (e) the run took under 60 s.
7. **`scripts/check.sh`** (`set -euo pipefail`):
   1. `luacheck mods/ tests/` with a repo `.luacheckrc` (std luajit; read-only globals core, vector, ItemStack, PcgRandom, VoxelManip, dump, minetest, mcl_mobs, mcl_util, and other mcl_* as needed; global `minemon` writable only in minemon_core);
   2. `busted tests/unit` (skip with a message if there are no specs);
   3. `python3 -m unittest discover -s tools/tests` if that dir exists;
   4. `bash scripts/assemble_game.sh`;
   5. every `tests/integration/*/` through run_luanti_test.sh (120 s timeout each).

   Print a summary and `CHECK PASSED`.
8. Update the CLAUDE.md "Key commands" only if your commands differ.

## Out of scope / files not to touch / permitted dependencies
- No gameplay mods beyond the minimal minemon_core stub.
- Allowed files: .gitignore, ASSETS_LICENSES.md, scripts/*, .luacheckrc, mods/minemon/modpack.conf, mods/minemon/minemon_core/* (stub only), tests/integration/smoke/*, and the CLAUDE.md Key commands section.
- Permitted dependencies: apt packages, Luanti, VoxeLibre (fetched, not committed).

## Acceptance criteria and verification
1. From a clean clone, `bash scripts/setup.sh && bash scripts/check.sh` exits 0 with the smoke test PASS. A second setup.sh run rebuilds nothing.
2. A temporary failing integration assertion makes check.sh exit 1. Revert it.
3. A temporary luacheck violation (an undefined global) makes check.sh exit 1. Revert it.
4. Report: the VoxeLibre tag pinned; smoke run time and peak RSS of luantiserver with VoxeLibre (`/usr/bin/time -v`); the assembled game size (`du -sh`).
5. `git status` shows no `.tools*` paths.
