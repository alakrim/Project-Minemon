# T-19 — Headless client screenshots (visual review in the container)
ID / milestone / wave / risk: T-19 / M1 / wave 0 / medium (tooling)

## Goal and why
The owner cares about beauty, and Opus must review visuals (world, creatures, effects) before every owner build. We need real screenshots of the Minemon game rendered by the real Luanti client inside the container (Xvfb plus Mesa software GL).

## Read
CLAUDE.md, docs/CONVENTIONS.md, scripts/setup.sh, scripts/versions.env, scripts/run_luanti_test.sh, docs/research/S-10-luanti-tooling.md.

## Steps
1. **Extend `scripts/setup.sh`** (keep it idempotent) with an optional client build behind a flag: `bash scripts/setup.sh --client`.
   - apt: the Luanti client deps on Ubuntu noble (libgl1-mesa-dev, libx11-dev, libxi-dev, libxxf86vm-dev, libpng-dev, libjpeg-dev, libfreetype-dev, libopenal-dev, libvorbis-dev, libogg-dev, libsdl2-dev if 5.17 uses SDL2; check the 5.17 README and CMake), plus xvfb, xauth, mesa-utils and imagemagick.
   - Build a client binary from the existing `.tools/luanti` source in a separate build dir: `-DBUILD_CLIENT=TRUE -DBUILD_SERVER=FALSE`, RUN_IN_PLACE. The binary lands in `.tools/luanti/bin/luanti`.
2. **`scripts/screenshot.sh <shots.json> <out_dir>`.** `shots.json` is `[{name, pos:[x,y,z], yaw_deg, pitch_deg, time_of_day:0..1, wait_s}]`. It:
   - assembles the game;
   - creates a fresh world (gameid minemon, fixed seed 1337, `mcl_` defaults);
   - adds a helper mod `tests/screenshot/minemon_shots`. On join, for each shot it: teleports the player, sets look yaw and pitch, sets the time of day, grants fly and noclip, hides the HUD (`player:hud_set_flags` all false), waits wait_s for chunks to load, then writes a marker file `shot_<name>.ready` to the world dir and waits until the script deletes it;
   - launches the client under `xvfb-run -a -s "-screen 0 1280x720x24"` with `--go --world <dir> --gameid minemon --name tester --password ""` (check the flags against 5.17 `src/main.cpp`), using the repo preset `scripts/presets/vega8.conf` as the client config (pass it with `--config`);
   - polls for each `.ready` marker, captures the X display with `import -window root <out_dir>/<name>.png`, deletes the marker, and continues;
   - kills the client after the last shot, then makes `contact.png`, a labelled grid of all shots at half size (ImageMagick montage).
3. **`tests/screenshot/default_shots.json`:** 6 shots near spawn for seed 1337:
   - plains_day;
   - forest_day;
   - mountain_view;
   - water_shore;
   - dusk (time 0.78);
   - night (0.0).

   Find meaningful positions by reading terrain heights in a headless run, or iterate.
