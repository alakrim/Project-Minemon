# T-15 — minemon_lives: 3 lives, 4th death = permadeath (ghost mode)
ID / milestone / wave / risk: T-15 / M0 / wave 1 / medium

## Goal and why
The owner's rule (D-009, D-025): each player has 3 lives; the 4th death is permanent. It must work per player in multiplayer and survive restarts.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (Invariants), docs/DECISIONS.md D-025. Luanti API docs: https://raw.githubusercontent.com/luanti-org/luanti/5.17.0/doc/lua_api.md (register_on_dieplayer, register_on_respawnplayer, register_on_joinplayer, hud_add, privileges, set_properties, chat commands).

## Interfaces / invariants
- **Files:** `mods/minemon/minemon_lives/` containing `mod.conf` (depends = minemon_core), `init.lua` (glue), `lives_logic.lua` (pure, no `core`).
  - If `mods/minemon/minemon_core` does not exist in your tree, create the same minimal stub T-14 defines: a `minemon` table and `minemon.version`. Note this in your report; Opus resolves the merge.
- **`lives_logic.lua`** exports pure functions over a state table `{lives=int, deaths=int, dead=bool}`:
  - `new_state(max)`;
  - `on_death(state, max)` returns `new_state, event`, where the event is `"lost_life"`, `"last_life"` or `"permadeath"`. Rules: lives start at max = 3; each death decrements; reaching 0 lives gives "last_life"; a death at 0 lives gives "permadeath" and `dead = true`. Deaths while already dead change nothing.
  - `give_life(state, max)`, capped at max;
  - `revive(state, max)`, a full reset;
  - `serialize` / `deserialize`: a compact string for player meta, robust to garbage (fall back to new_state).
- **Glue** (`init.lua`), API `minemon.lives = {get(player), give_life(player), revive(player), MAX = 3}`:
  - State lives in player meta key `minemon:lives:state`.
  - **On join:** load the state. A first join gets 3 lives and a chat message: "You have 3 lives. On your 4th death, your journey ends forever."
  - **HUD:** a small top-left text element `♥ 3` (red, with a dark outline if supported), updated on change. Dead players see `☠ Permadeath`.
  - **On die:** apply on_death and save.
  - **On respawn:**
    - "lost_life": a large centred HUD text "2 lives left" for 4 s, plus a sound if VoxeLibre has a suitable one (look one up, e.g. a wither or ghast-type sound in mcl_* mods; otherwise none).
    - "last_life": "LAST LIFE" in dark red, with a reminder in the HUD element.
    - "permadeath": enter ghost mode, show "YOUR JOURNEY ENDS" for 6 s, and chat-broadcast "<name> has fallen forever."
  - **Ghost mode:** revoke `interact` (remember the previous privileges in meta), grant `fly` and `noclip`, make the player invisible (`set_properties` visual_size 0, pointable false, nametag hidden), and disable damage while dead (`set_armor_groups({immortal=1})`).
  - **Rejoin while dead:** ghost mode is re-applied.
  - **Chat commands:**
    - `/lives`: shows "Lives: N/3", or "Permadeath";
    - `/lives_revive <name>` (privilege `server`): revives the player and restores their privileges and visibility;
    - `/lives_give <name>` (privilege `server`).
