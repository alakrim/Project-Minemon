# T-16 — Portable Windows build with a Vega 8 graphics preset
ID / milestone / wave / risk: T-16 / M0 / wave 2 / medium
Depends on: T-14 (scripts/assemble_game.sh, scripts/versions.env).

## Goal and why
The owner (no coding skills, D-010) must be able to download, unzip and play Minemon on Windows, and it must look good while running at least 30 fps on an AMD Vega 8 with 6 GB RAM.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (M0 row), scripts/versions.env, scripts/assemble_game.sh. Luanti setting names come from https://raw.githubusercontent.com/luanti-org/luanti/5.17.0/builtin/settingtypes.txt (fetch it and use only names that exist there).

## Steps
1. **`scripts/build_windows.sh`:**
   - (a) Download `https://github.com/luanti-org/luanti/releases/download/${LUANTI_TAG}/luanti-${LUANTI_TAG}-win64.zip` once into `.tools/cache/`.
   - (b) Unpack it into `builds/Minemon/` (the zip has a top folder, so flatten it so that `builds/Minemon/bin/luanti.exe` exists).
   - (c) Run `bash scripts/assemble_game.sh` and copy `.tools/games/minemon` to `builds/Minemon/games/minemon`.
   - (d) Write `builds/Minemon/minetest.conf` (the portable install reads the conf next to bin/; check the file name and location used by 5.17 portable Windows builds in the source, `RUN_IN_PLACE`, and use the correct one) with the preset below.
   - (e) Write `builds/Minemon/Play Minemon.bat` (CRLF). It starts `bin\luanti.exe` so that the main menu opens with Minemon selected. Use the `menu_last_game = minemon` setting. If 5.17 supports going straight into a world with `--go --worldname`/`--world` plus `--gameid`, also add `Quick Play.bat`, which creates or opens the world `worlds/Minemon` directly. Verify the flags in `src/main.cpp`, and only add it if the flags exist.
   - (f) Write `builds/Minemon/LEIA-ME README.txt`: Portuguese headings, simple English body.
     - How to start, and that Windows SmartScreen may warn ("More info → Run anyway").
     - Controls: WASD, mouse, Space, Shift (sneak), E (inventory), and F5 for the debug info with FPS.
     - "Tell Claude the FPS number shown at the top-left after pressing F5, in a forest during the day".
     - The rule: 3 lives, then permadeath (`/lives` to check).
   - (g) Zip `builds/Minemon/` to `builds/Minemon-M0-windows.zip`, then split it into parts of at most 25 MB (`Minemon-M0-windows.zip.001` …) and write `JUNTAR-JOIN Minemon.bat` (CRLF). It joins the parts with `copy /b` in order and tells the user to right-click the zip and choose Extract All.
2. **Graphics preset for the Vega 8** (beautiful but cheap). Use only names that exist in the 5.17 settingtypes.txt:
   - viewing range around 120;
   - fog on;
   - dynamic shadows on, with a 1024 shadow map, low filtering and short shadow distance;
   - bloom on (light);
   - waving leaves, plants and water on;
   - FXAA (or the cheapest AA) on;
   - automatic exposure on if it exists;
   - volumetric light off;
   - fps_max 60, vsync off;
   - mip-mapping and anisotropic filtering on;
   - smooth lighting on;
   - `menu_last_game = minemon`.

   Document each setting with a comment explaining why. Also add `scripts/presets/low.conf` with the same keys minus shadows and bloom, and a viewing range of 80, as the fallback the README mentions: "If FPS is below 30, replace minetest.conf with presets\low.conf". Copy the presets folder into the build.
3. **Headless sanity:** run the existing integration smoke test against the copied game in `builds/Minemon/games/minemon` (point the runner at it if the runner supports a game dir argument; otherwise note it) to prove the shipped game files load.

## Out of scope / files not to touch / permitted dependencies
- Allowed files: scripts/build_windows.sh, scripts/presets/*.conf, and an optional new flag in scripts/run_luanti_test.sh for the game dir (do not change its default behaviour).
- No gameplay changes.

## Acceptance criteria and verification
1. `bash scripts/build_windows.sh` exits 0 and produces the zip parts plus the join .bat. Report each part's size and the total. `cat parts | md5sum` equals the zip's md5.
2. `unzip -l` lists `bin/luanti.exe`, `games/minemon/game.conf`, `minetest.conf`, `Play Minemon.bat`, `LEIA-ME README.txt` and `presets/low.conf`.
3. Every key in both presets exists in settingtypes.txt. Show it with a script that checks this.
4. `bash scripts/check.sh` still exits 0.
