# T-26 — minemon_capture: thrown balls, catch odds, shakes, break-free, creature_defeated event
ID / milestone / wave / risk: T-26 / M2 / wave 1 / high (core loop; edits the creature runtime choke point, so Opus reviews the diff)

## Goal and why
Catching is the heart of a Pokémon game. The player weakens a wild creature until it is exhausted, then throws a ball at it. The ball shakes up to 3 times, a tense moment, and then either clicks shut or the creature bursts out enraged. See D-030.

## Interfaces / invariants
- **Runtime edits** (the only edits allowed in minemon_creatures; keep them small):
  - (a) In `runtime.lua` `on_zero_hp`, when a **wild** creature becomes exhausted, fire `minemon.events.fire("creature_defeated", le, attacker)`, where `le` is the luaentity and `attacker` is the attacker ObjectRef or nil. This is the contract event.
  - (b) Add `M.break_free(obj, aggressor_obj)`. It ends exhaustion as `recover` does (25% HP, nametag suffix removed). Then, instead of fleeing, the creature becomes hostile: `passive=false`, `do_attack(aggressor)` if valid, and `_mm_enraged_t = 30`. While `_mm_enraged_t > 0` it counts down. The wild brain is not edited; enraged creatures just use mcl's attack state. Export it as `minemon.creatures.break_free`.
  - Add unit tests for any new pure helper in runtime_logic.lua.
- **New mod `minemon_capture`.** It depends on minemon_core, minemon_creatures and minemon_party, with optional dependencies mcl_throwing, vl_projectile and mcl_sounds. Pure logic goes in `capture_logic.lua` (no `core`).
- **Balls:** register `minemon:poke_ball`, `minemon:great_ball`, `minemon:ultra_ball` and `minemon:master_ball` (leading-colon names; D-030). The description comes from items.json, plus a tooltip line "Catch rate ×N". Each has a generated 16×16 icon from `tools/gen_icons.py`, our own art in the same style as the Party Ball: red/white, blue/white with red marks, black/yellow, purple/white with an "M"). `stack_max` 64.
- **Crafting** (grind), using VoxeLibre items. Verify that the names exist in `.tools/voxelibre` and pick close substitutes if not:
  - Poké Ball: shaped, iron_nugget over redstone over iron_nugget, gives 2;
  - Great Ball: Poké Ball + lapis lazuli, shapeless;
  - Ultra Ball: Poké Ball + gold ingot + obsidian, shapeless;
  - Master Ball: no recipe.
- **Throw:** left click (`on_use`) throws the ball, as an `mcl_throwing` snowball does: speed about 22, slight gravity, and one item consumed unless in creative mode. The flying entity uses `visual="wielditem"` showing the ball item, and plays a VoxeLibre throw sound.
- **On hitting an object:**
  - not one of our creatures, or one that is owned: drop the ball item at that spot;
  - a creature that is not exhausted: the ball bounces (drop the item) with the chat message "It's too strong — weaken it first!", and the creature targets the thrower (`do_attack`);
  - an exhausted wild creature: start the capture sequence.

  On hitting a node, drop the ball item.
- **Capture sequence:**
  - The creature entity is hidden: set it invisible with `set_properties({is_visible=false})`, freeze it, and mark it `_mm_capturing = true` so damage and brains ignore it. Check that exhausted creatures already ignore damage.
  - A ball entity sits on the ground at the creature's position.
  - Shake checks: use `capture_logic.shakes(p, rng)`, where p = `minemon.formulas.catch_chance(species.catch_rate, hp_frac, ball_mult, inst.status)`. It returns `(n_shakes 0..3, caught bool)` from the Gen 3+ shake probability, with each shake passing at probability `p^(1/4)` so the catch probability equals p. Master Ball always catches.
  - Each shake is about 0.9 s: the ball entity rotates side to side, with a click sound.
  - If the exhausted timer runs out during the sequence, the timer is paused.
- **Success:**
  - Chat line "Gotcha! <Name> was caught!", in gold. Show particles and a VoxeLibre level-up or chime sound.
  - Remove the creature entity with `mcl_util.remove_entity`.
  - Update the instance: `owner` = player name, `ball` = ball id, `bond` = 70, hp kept, status kept.
  - If the party has fewer than 6 members, append the creature through `minemon.party.set`. Otherwise call `minemon.pc.deposit(player, inst)` if `minemon.pc` exists (T-28 provides it) and say "<Name> was sent to the PC." If neither works, give the instance back by releasing it: the creature stays wild and recovers.
  - Fire `creature_captured(player, inst)`.
- **Failure:**
  - "Oh no! <Name> broke free!", in red. The ball breaks: puff particles and no item back.
  - Make the creature visible again and call `minemon.creatures.break_free(obj, player)`.
- **Catch odds hint:** every 0.25 s, for each player wielding a ball, raycast 24 nodes. If the ray hits an exhausted wild creature, show a HUD text near the crosshair: "Catch ~NN%", coloured green ≥ 60, yellow ≥ 25, red below. Hide it otherwise.
- **Starter kit:** on join, if the party is non-empty and the player meta flag `minemon:capture:kit` is unset, give 5 Poké Balls and set the flag. Check again 2 s after `creature_sent_out` too, so fresh starters get the kit.
- **Admin command:** `/give_balls [n]` (privilege give).
