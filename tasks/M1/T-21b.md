# T-21b — Wild creature brain: temperament, the aggression gate, danger tuning, spawn fixes
ID / milestone / wave / risk: T-21b / M1 / wave 3 / high (the game's difficulty and feel)

## Goal and why
The owner's core experience: the wild must feel alive and dangerous. In the first days a wild Rattata is a real threat. Aggressive species hunt you when you have no Pokémon out, and fight your Pokémon when you do (D-009, D-026).

## Interfaces / invariants
- **Wild brain** in `minemon_creatures/wild_brain.lua`, plus pure decision logic in `wild_logic.lua`. It is registered with `register_brain("wild", fn)`, applies only to entities without an owner, and is throttled to every 0.5 s per entity (spread the timers randomly so not all creatures think on the same step).
- **Decision:** `decide(ctx)` is pure and returns one of `{action="hunt_player", target}`, `{action="fight_creature", target}`, `{action="flee"}`, `{action="idle"}`. `ctx` = {temperament, types, hp_frac, is_night, nearest player and distance, whether that player has an active creature and its distance, angry_until, now, view_range}.
  - **aggressive:** a player in view_range (×1.5 at night) with an active creature within 16 nodes of us gives fight_creature on that creature; without one, hunt_player.
  - **territorial:** the same as aggressive, but only if the player is within 5 nodes or `angry_until > now`. Being hurt sets angry_until = now + 30 s. At night, Ghost/Dark/Poison types behave as aggressive.
  - **skittish:** a player within 8 nodes gives flee. When hurt: flee.
  - **peaceful:** idle. When hurt: flee, unless the attacker is a creature, in which case it fights back once (angry for 10 s).
  - **Any temperament:** at hp_frac below 0.2, flee, except aggressive at night (fight to the end).
- **Actions:**
  - hunt_player: `self:do_attack(player)`; mcl dogfight melee does the damage.
  - fight_creature: `self:do_attack(creature)`, plus `minemon.combat.choose_move` and `use_move` when in range.
  - flee: `self.state = "runaway"`, `self.runaway_timer = 0` (S-12 §3).
  - idle: return nil, so mcl wanders.

  Return "skip_states" only when necessary.
- **Danger tuning** (player-facing melee): set `self.damage = max(2, floor(1.5 + level*0.15 + atk/20 + 0.5))` and `attack_frequency` from spe: 1.2 s minus spe/200, minimum 0.5. Group spawns of small aggressive species: 2–3. Wild creatures hunting a player get +20% run velocity. Document the resulting numbers for Rattata L3 and L5, Spearow L4 and Raticate L20 (bite damage, bites per second, time to kill a 20-HP unarmoured player) in your report. The target is that a single L3 Rattata takes about 12–20 s to kill an unarmoured player who doesn't fight back, and two of them about half that.
- **Hurt hook:** subscribe to `minemon.events` `creature_hurt` to set angry_until on wild creatures and remember the attacker as a candidate target.
- **Fixes from the T-21a verdict:**
  - **(a)** Eldritch species MUST spawn normally (Onix, Gastly line, Gyarados, Lapras, Snorlax and the rest). The `eldritch` flag only marks titan candidates (M5). Exclude only legendaries and mythicals, starters and Unown.
  - **(b)** The flaky creatures integration test ("no centre with 10 dry columns"): widen the centre search (more candidates) or generate a flat platform with `core.set_node` before spawning, so it is deterministic.
  - **(c)** `key_for` must match the registered names for display names: "Farfetch'd" → farfetchd, "Nidoran♀" → nidoran_f, "Nidoran♂" → nidoran_m. Use the data's canonical lowercase names, and add tests.
