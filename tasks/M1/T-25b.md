# T-25b — Bake Cobblemon animations (idle, walk, attack, faint, sleep) into the pack .glb files
ID / milestone / wave / risk: T-25b / M1 / wave 5 / high (visual quality)

## Goal and why
Cobblemon models rely on their animations for their pose: the T-25a rest poses of Onix and Gyarados look wrong. Bake real animations into each .glb so creatures look and move like Cobblemon's, using our standard frame ranges so creatures switch models without code changes.

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/DECISIONS.md D-029, docs/research/S-13-shortcuts.md (clip names; Molang via the `molang` PyPI package; kirbycope `poses.py`), tools/cobblemon_import.py and tasks/M1/T-25a.report.md, tools/gen_standins.py (frame ranges).
Source: `.tools/cobblemon-bedrock/development_resource_packs/cobblemon/animations/<NNNN>_<name>/<name>.animation.json`. Read the repo's `poses.py` and `port.py` first: they map Cobblemon poser names to Bedrock animations (shortcut).

## Interfaces / invariants
- Extend `tools/cobblemon_import.py` (permitted dev deps: `molang`, `pygltflib`). Each .glb gets ONE clip with these frame ranges (seconds = frames, speed 1.0, the same as the stand-ins):
  - stand 0–20 ← ground_idle (fallback: battle_idle, then any "idle");
  - walk 21–41 ← ground_walk;
  - run 42–52 ← ground_run (fallback: walk sped up);
  - punch 53–63 ← physical or an attack clip (fallback: a quick forward lunge of the root);
  - die 64–74 ← faint (fallback: a roll onto the side);
  - sit 75–85 ← sleep (fallback: a squat).
- Flyers (`air_fly`/`air_idle`) and swimmers (`water_swim`) use those for stand and walk when the species is avian or fish (our data's body_plan).
- **Baking:** sample each bone's rotation, position and scale keyframes at 1-frame steps. Evaluate Molang expressions with the `molang` package; `q.anim_time`/`query.anim_time` is the clip time, and unknown queries (q.look, q.walk_speed and similar) are 0. Loop clips are time-scaled to fill their range. Bedrock animation values are deltas added to the rest pose (rotation in degrees, Bedrock axis signs consistent with T-25a), so apply them to the rest transforms.
- **The rest pose itself:** if a species' idle clip is the "pose", sampling it fixes the look. Also write the frame-0 idle pose as the node rest transform, so that a frozen model looks posed.
- Write per-species metadata into minemon_pack init.lua: `anims = {stand={0,20}, walk={21,41}, ...}` (always the same ranges) and `scale_hint` from the model's bounding box.
