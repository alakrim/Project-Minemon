# T-22 — minemon_party: starter choice, party, Party Ball, owned creature brain, party HUD
ID / milestone / wave / risk: T-22 / M1 / wave 3 / high (core loop; player-facing)

## Goal and why
The player needs their own Pokémon: pick a starter, send it out, recall it, and order attacks in real time. The owned creature follows, defends and fights using the combat system (D-026). This also provides `minemon.party.get_active` for the aggression gate (T-21b).

## Interfaces / invariants
- **Mod `minemon_party`:** depends = minemon_core, minemon_creatures, minemon_combat, mcl_formspec (optional). Pure logic goes in `party_logic.lua`.
- **Storage:** player meta `minemon:party:list`, a JSON array (max 6) of serialized instances. API per the contract: `get(player)`, `set(player, list)`, `get_active(player)`, `send_out(player, index)`, `recall(player)`, plus `lead_index(player)` and `heal_all(player)` (admin and tests).
- **Starter:** on join with an empty party (and not dead per minemon.lives), show a formspec titled "Choose your partner" with 6 buttons: Bulbasaur, Charmander, Squirtle, Chikorita, Cyndaquil, Totodile. Each button shows the type name and a coloured box in the type colour. The choice gives a level 5 instance, the item `minemon_party:party_ball` and the chat line "<Name> joined you. Stay close — the wild is dangerous." Closing the formspec without choosing reopens it after 3 s, up to 5 times, then `/starter` reopens it.
- **Party Ball item** (`minemon_party:party_ball`, a generated 16×16 icon: a red and white sphere drawn by our Python tool, our art). Use VoxeLibre's hand-item conventions.
  - **on_place / on_secondary_use (right click):** if no active creature, send out the lead (the first creature with HP above 0) 2 m in front of the player and show the message "Go, <Name>!". If one is active, recall it ("<Name>, come back!"). With sneak held, open the party formspec: a list with name, level, HP bar and status, and a "Make lead" button per row.
  - **on_use (left click) pointing at an object:** if it is a creature that is not ours, set it as our active creature's ordered target and show "<Name>, attack!"; otherwise do nothing. It never damages the target itself.
- **Active tracking:** one active creature per player, kept in a Lua table by player name (not persisted). The owned entity is spawned with `minemon.creatures.spawn(pos, species_id, level, owner)`, after which its `_mm` is replaced by the party instance (same uid).
  - **Write-back:** the entity's `_mm` goes back into the party list (by uid) on recall, faint, leave, death and every 5 s.
  - On player death or leave: recall with write-back.
  - On server restart, any owned entity with no active record is removed on activation, using the uid lookup.
- **Faint:** handle `creature_fainted`: write back hp 0, remove the entity, show "<Name> fainted!" in red, and set the next lead.
- **Regeneration:** recalled creatures regain 1 HP every 8 s (not fainted ones: they need a Pokémon Center, which arrives in M4). A fainted creature is revived to 1 HP after 10 minutes of real play time, so the early game is never soft-locked.
- **Owned brain** (`register_brain("owned", fn)`), only for entities with an owner, every 0.25 s:
  - **(1)** If the owner is offline, recall and remove.
  - **(2)** If more than 24 nodes from the owner, teleport to 2 m behind the owner.
  - **(3)** If there is a valid ordered target (exists, not exhausted, within 32), or failing that, the nearest wild creature within 10 nodes that is targeting the owner or us (its `self.attack` is the owner or us): set `self:do_attack(target)` so mcl approaches, and every tick try `minemon.combat.choose_move` then `use_move` when the target is within the move's range_m.
  - **(4)** Otherwise follow the owner: walk toward the owner when more than 4 nodes away, and stand when within 3.

  Return "skip_states" when the brain handles movement, so mcl's random wander does not fight it. Ordered targets that become exhausted are cleared and the owner sees "<Target> is exhausted! (capture comes soon)".
- **Party HUD** (top-right, small, one line per party member): "● Cyndaquil Lv5 18/20" in white, yellow below 50%, red below 20%, grey when fainted. The active member is marked ▶. It updates on change and at most every 0.5 s.
- **Chat commands:** `/party` lists the party in chat; `/starter` reopens the chooser if the party is empty; `/heal_party` (privilege server) heals all.
