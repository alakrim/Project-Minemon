# T-21a — minemon_creatures: registration of 251 species, levels, health, nametags, spawning
ID / milestone / wave / risk: T-21a / M1 / wave 1–2 / high (core gameplay entity)

## Goal and why
Kanto + Johto creatures must appear in the VoxeLibre world by biome, with levels that rise with distance from spawn, using our stand-in visuals. This is the base for temperament AI (T-21b), combat (T-23) and the party (T-22).

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (the M1 interface contract and Invariants), docs/DECISIONS.md D-026, docs/research/S-12-voxelibre-mobs-api.md (read all of it; it has file:line references into `.tools/voxelibre`), mods/minemon/minemon_core/data/species.json (the fields). T-20 (the minemon_core API) and T-18 (models and textures) are being built in parallel: **code against the contract**. If `minemon.data` / `minemon.formulas` / `minemon.instance` are missing in your tree, add a clearly marked temporary shim file `minemon_creatures/shim_core.lua`, loaded only when `minemon.data == nil`, that implements just what you need (loading species.json via `core.parse_json`, calc_stats, wild_level). Opus deletes it at merge. Likewise, if the model and texture files are missing, reference the contract names `mm_<body_plan>.glb` and `mm_type_<type>.png`, and use VoxeLibre's `mobs_mc` pig model temporarily in tests only.

## Interfaces / invariants
- **Mod `minemon_creatures`:** mod.conf depends = minemon_core, mcl_mobs, mcl_util; optional_depends = mcl_biomes. Files: init.lua (glue), `defs.lua` (pure: builds the mcl_mobs def table from species data; testable with busted), `spawning.lua`, `habitats.lua` (pure: habitat tag → VoxeLibre biome names).
- **Registration:** for each of the 251 species, `mcl_mobs.register_mob("minemon_creatures:" .. key, def)`, where key = lowercase name with non-alphanumerics replaced by `_` (mr_mime, farfetch_d, nidoran_f, nidoran_m, ho_oh).
  - `spawn_class` = "hostile" for aggressive/territorial, "passive" for skittish/peaceful.
  - `type` = "animal", `passive` = false for aggressive/territorial and true for the others. T-21b owns the targeting.
  - `visual` = "mesh", `mesh` = "mm_" .. body_plan .. ".glb", `textures` = {{"mm_type_" .. types[1] .. ".png"}}.
  - `visual_size` and collisionbox scale from size_class: tiny 0.5, small 0.8, medium 1.2, large 1.8, huge 2.6, colossal 3.5. Eldritch giants come in M5.
  - `walk_velocity`/`run_velocity` from spe: walk 0.8 + spe/150, run walk × 2.
  - `view_range` = 12 (+6 if aggressive).
  - `fly` for avian, swimming handled via `fly_in` water for fish, with `breathes_in_water` for fish.
  - `damage` = 1 + floor(atk/30) and `reach` 2.5: the player-facing melee danger. T-21b scales it per level.
  - `animation` keys matching T-18's ranges: stand 0–20, walk 21–41, run 42–52, punch 53–63, die 64–74, sit 75–85.
  - `drops` = {} (no meat); `can_despawn` = true for wild.
- **Instance and health:** `on_spawn`: if `self._mm` is nil, create the instance with `minemon.instance.new(species, level, rng)`, where level = `minemon.formulas.wild_level(distance of pos from (0,0,0) in xz, is_night, rng)`. Then:
  - set `self.health` and `self.hp_max` (and the object HP) to the instance HP;
  - set `self.damage` = 1 + floor(stats.atk/25 + level/10);
  - set the nametag "Rattata Lv 4" (white; red for aggressive species).

  Persist `_mm` (mcl_mobs saves every non-function field).
- **Public API** (contract): `minemon.creatures.spawn(pos, species_id, level, owner_name)` returns an ObjectRef with an instance at that level. If an owner is given: `can_despawn` = false, `persistent` = true, `tamed` = true, `owner` = name, and no wild nametag colour.
  - `get_instance(obj)`; `is_exhausted(obj)` (always false in this task: T-21b implements it); `key_for(species)`.
- **Spawning:** a habitat → biome map in habitats.lua:
  - plains: Plains, SunflowerPlains, Savanna;
  - forest: Forest, FlowerForest, BirchForest, RoofedForest;
  - mountain: ExtremeHills*;
  - cave: underground (type_of_spawning ground, max_height 0);
  - water: rivers and oceans (water spawning);
  - sea: ocean biomes;
  - desert: Desert, Mesa*;
  - snow: IcePlains, ColdTaiga;
  - swamp: Swampland, MangroveSwamp;
  - urban: Plains;
  - rare: none (no natural spawn).

  Read the exact biome names from `.tools/voxelibre/mods/MAPGEN/mcl_biomes/init.lua`.
  - Each species calls `mcl_mobs:spawn_setup{...}` with `chance` derived from catch_rate (common = high catch_rate) and `spawn_in_group` 1–3 for small species, 1 otherwise.
  - Exclude: legendaries and mythicals (Articuno, Zapdos, Moltres, Mewtwo, Mew, Raikou, Entei, Suicune, Lugia, Ho-Oh, Celebi), the eldritch flag, evolved stages above 2 (evolved forms spawn 4× rarer), starters (1, 4, 7, 152, 155, 158 families do not spawn naturally), and Unown.
  - Spawn tiering by level: a species may spawn only where `wild_level` is at least its "min spawn level" = 2 for unevolved, 16 for stage 2, 30 for stage 3. Implement this as a `check_position` that computes the level at that position (S-12 §2).
  - Do NOT use `mcl_mobs.custom_biomecheck` (bug, S-12).
- **Disable hostile vanilla mobs:** add to `scripts/presets/vega8.conf` and `low.conf` one line per hostile mobs_mc entity (`mobs_mc:zombie = 0`, etc.). Read the entity names from `.tools/voxelibre/mods/ENTITIES/mobs_mc/`; skeleton, zombie, creeper, spider, cave_spider, enderman, witch, slime, drowned, husk, stray, phantom, pillager, vindicator, evoker, silverfish, and so on; keep passive farm animals and villagers. Also add the same lines to the test-world config in `scripts/run_luanti_test.sh` only if that is needed to keep tests fast (optional).
