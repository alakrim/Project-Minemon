# T-25c — Creatures use the Cobblemon pack models (fall back to stand-ins)
ID / milestone / wave / risk: T-25c / M1 / wave 6 / medium

## Goal and why
Every creature, wild and owned, shows its real model and texture (D-029) when the generated pack is present, and our stand-in otherwise.

## Read
CLAUDE.md, docs/CONVENTIONS.md, mods/minemon/minemon_creatures/{defs.lua, init.lua}, the generated `.tools/pack_cobblemon/minemon_pack_cobblemon/init.lua` (format: `minemon_pack.models[dex] = {mesh, texture, texture_shiny, height, width, anims, scale_hint}`), tasks/M1/T-25b.report.md, tasks/M1/T-18.report.md (animation speeds).

## Interfaces / invariants
- `minemon_creatures/mod.conf`: optional_depends adds `minemon_pack_cobblemon`.
- defs.lua (pure) gains `visual_for(species, pack_entry_or_nil, shiny)`, which returns `{mesh, textures, visual_size, collisionbox, selectionbox, animation}`.
  - With a pack entry: the pack mesh and texture, with visual_size 1 (the models are at true Cobblemon scale). The collisionbox comes from the pack width and height (clamped to 0.3–3.0 wide and 0.3–4.0 tall).
  - Without one: the current stand-in behaviour.
  - The animation table uses the shared frame ranges, with speeds stand 4, walk 20, run 30, punch 14, die 10, sit 6.
- **Shiny:** the instance's `shiny` field (1/512 chance at wild spawn; add this to `minemon.instance.new` only if absent, coordinating with T-20 code) selects texture_shiny, set in on_spawn and after_activate via set_properties.
- The registration path uses `visual_for`. Instances spawned before this change keep working.
