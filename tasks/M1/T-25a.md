# T-25a — Cobblemon Bedrock → Luanti glTF converter (geometry, textures, skeleton)
ID / milestone / wave / risk: T-25a / M1 / wave 4 / high (visual identity)

## Goal and why
Real Pokémon visuals (owner directive D-029). Convert the Bedrock models for dex 1–251 from the pinned cobblemon-bedrock clone into `.glb` files that Luanti 5.17 renders correctly, with textures and a bone hierarchy ready for animation (T-25b).

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/DECISIONS.md D-029, docs/research/S-11-creatures-pipeline.md (Luanti glTF facts and Bedrock format notes), `tools/gen_standins.py` (our working stdlib GLB writer: reuse it), `.tools/luanti/doc/lua_api.md` (glTF section).
- **Source:** `git clone --depth 1 https://github.com/kirbycope/cobblemon-bedrock .tools/cobblemon-bedrock`. Pin the commit in scripts/versions.env as `COBBLEMON_BEDROCK_COMMIT`, and add the clone to scripts/setup.sh.
- **Layout:**
  - models: `development_resource_packs/cobblemon/models/entity/<NNNN>_<name>/<name>.geo.json` (some have only `_male`/`_female`: use `_male`);
  - textures: `textures/entity/<NNNN>_<name>/<name>.png` and `<name>_shiny.png`.

  Read that repo's `port.py`, `poses.py` and `tools/` first: they may contain parsing helpers or format notes (shortcut).

## Interfaces / invariants
- **`tools/cobblemon_import.py`** (python3; permitted dev-only deps: `pygltflib`, `molang` via pip --break-system-packages, plus the stdlib GLB writer in gen_standins.py; see docs/research/S-13-shortcuts.md). Usage: `--src .tools/cobblemon-bedrock --out .tools/pack_cobblemon [--only 19,25]`. It writes `.tools/pack_cobblemon/minemon_pack_cobblemon/` containing:
  - `mod.conf`;
  - `init.lua`, defining the global `minemon_pack` with `models[dex] = {mesh, texture, texture_shiny, height, width}`, declared with rawget;
  - `models/mmp_NNNN.glb`;
  - `textures/mmp_NNNN.png` and `mmp_NNNN_s.png`;
  - `CREDITS.txt` (attribution, licence notice, "modified: format conversion").
- **Geometry:**
  - 16 px = 1 block.
  - Bones become glTF nodes with parent and pivot-relative rest transforms, plus the bone `rotation` (degrees; check Bedrock's axis sign conventions visually).
  - Cubes become 6 quads from origin, size and inflate, with the cube rotation and pivot applied.
  - Box UV uses the Minecraft unwrap, with `mirror` flipping U; per-face UV is the dict form. UVs are normalised by texture_width and texture_height.
  - One skinned mesh with JOINTS_0/WEIGHTS_0, each vertex 100% on its bone.
  - Facing must match our stand-ins (compare gen_standins.py). Scale so that 1 block = 1 node in game, the same as our stand-ins. Feet at y = 0.
- Rest pose only (animations come in T-25b); keep the bone names.
