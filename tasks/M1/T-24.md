# T-24 — Creature runtime hooks: brains, the single damage path, exhausted and faint states
ID / milestone / wave / risk: T-24 / M1 / wave 2 / high (an interface every M1 gameplay task uses; Opus reviews the diff)

## Goal and why
Party (T-22), wild AI (T-21b) and combat (T-23) must plug into creatures without editing the same code, and HP must never desync between the entity and the saved instance (D-027).

## Read
CLAUDE.md, docs/CONVENTIONS.md, docs/PLAN.md (the M1 contract and addendum D-027), docs/research/S-12-voxelibre-mobs-api.md (§1 hooks: do_custom, deal_damage, do_punch, on_die; §4 damage), mods/minemon/minemon_creatures/*.lua, and the VoxeLibre files S-12 cites for `deal_damage`, `do_punch`, `damage_mob` and `on_die`.

## Interfaces / invariants
Implement exactly the addendum API. Details:
- **`do_custom` dispatcher:** run the brains in order. Return values: `true` stops the chain; "skip_states" stops the chain and returns false to mcl_mobs, so `do_states` is skipped. Any error in a brain is caught with pcall and logged once per brain per minute, so a broken brain never kills the mob.
- **Damage path:**
  - `deal_damage(self, damage, reason)` is overridden in every def to route into `minemon.creatures.damage(self.object, damage, reason.source or reason.direct, {source="mcl", type=reason.type})`.
  - Damage while exhausted is ignored for wild creatures: you can't kill an exhausted creature (capture comes in M2).
  - Player punches still go through mcl_mobs `do_punch`, then `deal_damage`. Check that the path really reaches `deal_damage`; if mcl_mobs subtracts `self.health` directly anywhere, intercept it via `do_punch` returning false and applying damage yourself. Document what you found with file:line.
- **Exhausted (wild):** stop movement (`self.state = "stand"`, velocity 0); loop the sit animation; `self.attack = nil`; `self.passive = true` while exhausted; nametag suffix " (exhausted)". After 20 s: restore `passive` from the species temperament, heal to 25% of max, set `state = "runaway"` and `runaway_timer = 0` (S-12 §3), and clear the flag. Persist the flag and the remaining timer in `_mm_exhausted_t`.
- **Owned faint:** fire the event; if no handler removes the object within 0.5 s, remove it yourself and log a warning.
- **mcl_mobs death:** a creature must never die through mcl_mobs' own death path. `on_die` returns true and calls `on_zero_hp` as a safety net, for void or other kills; `/clearobjects` is fine.
- **Visual feedback:** a red damage tint via `set_texture_mod("^[colorize:#ff000060")` for 0.2 s, and small particles on hit (a VoxeLibre texture that exists, or a generated 4×4 white PNG tinted).
