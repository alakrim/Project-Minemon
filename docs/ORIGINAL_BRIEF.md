Project:

I want to build a "minecraft + pokemon". But importantly: I want something easy to run on low build pcs, but beautiful enough.
I want a well structured system, starting with all the Kanto and Johto Pokemons. Pokemons should have level, the more you battle with them and play with them, they get more levels. Pokeball system, different pokeballs, different catch rate. To try and capture a pokemon, you must beat it first.
Some pokemons are aggressive and some are pacific.
Different skills have different animations.
Brainstorm ideas to make this a complete game.
The game must feel alive, and very hard. For the few days, a wild rattata must feel like a challenge. The map should feel enticing, and scary to navegate as well.
Missions, all the Kanto + Johto cities.
Some of the bigger pokemons must feel almost like an eldritch creature, truly scary.
